# Запуск объединённого LogicPulse

Главный бот находится в папке `LogicPulse_Bot`. Папка `TgLP3` в архиве
содержит только старую базу командных задач, которую LogicPulse импортирует
автоматически при первом запуске.

## Быстрый запуск на Windows

1. Распакуйте архив целиком, не разделяя папки `LogicPulse_Bot` и `TgLP3`.
2. Откройте папку `LogicPulse_Bot`.
3. Скопируйте `.env.example` в новый файл `.env`.
4. Вставьте токен основного Telegram-бота в `BOT_TOKEN`.
5. Для AI-помощника заполните `OPENAI_API_KEY`. Адрес Cloud.ru и модель
   `deepseek-ai/DeepSeek-V4-Pro` уже указаны в `.env.example`.
   Если оставить ключ пустым, задачи и напоминания продолжат работать без AI.
6. Установите Python 3.11 или новее.
7. Выполните:

```powershell
python -m venv venv
venv\Scripts\python -m pip install -r requirements.txt
venv\Scripts\python main.py
```

После запуска отправьте боту команду `/start`. Личные задачи находятся в
разделе «Мои планы», а функции второго бота — в разделе «Командное
пространство».

Бесплатные локальные инструменты находятся в разделе «Инструменты»:

```text
Нажмите кнопку «Создать QR-код»
/calc (1250 * 18%) + 340
```

QR-коды и калькулятор не используют AI API и не расходуют баланс провайдера.

Для проверки AI нажмите «🧠 AI-помощник» или отправьте:

```text
/ai Создай командную задачу подготовить отчёт для клиента
```

Секретный файл `.env` намеренно не включён в архив.
