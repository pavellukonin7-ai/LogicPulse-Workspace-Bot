# LogicPulse MVP + AI + Tools

Версия 1.1.0 добавляет два бесплатных локальных инструмента:

- `Создать QR-код` — понятная кнопка для генерации крупного PNG без сжатия;
- `/calc выражение` — безопасные сложные вычисления без обращения к AI API.

## Что входит в MVP

- один Telegram-бот и один системный сервис;
- личные задачи с городом, датой, временем и напоминанием;
- общее командное пространство;
- завершение, удаление, история и CSV-экспорт;
- AI-помощник для работы с задачами обычным текстом;
- сохранение существующей SQLite-базы при обновлении;
- автоматический запуск и перезапуск через systemd.

## Что умеет AI-помощник

- создавать личную задачу;
- создавать общую командную задачу;
- завершать личную или командную задачу по номеру;
- составлять сводку по текущим задачам;
- подсказывать приоритеты и разбивать большую задачу на шаги.

AI никогда не записывает изменение сразу. Сначала бот показывает карточку
действия, после чего пользователь нажимает «Подтвердить» или «Отмена».

Для подготовки ответа имя пользователя и активные задачи передаются тому
AI-провайдеру, который указан в `OPENAI_BASE_URL`. Не добавляйте в задачи пароли,
токены, платёжные данные и другие секреты.

## Настройка

В рабочем `.env` должны быть указаны:

```dotenv
BOT_TOKEN=...
OPENAI_API_KEY=...
OPENAI_BASE_URL=https://foundation-models.api.cloud.ru/v1
OPENAI_MODEL=deepseek-ai/DeepSeek-V4-Pro
TEMPERATURE=0.8
MAX_TOKENS=1000
MAX_CONTEXT_MESSAGES=20
REQUEST_TIMEOUT_SECONDS=120
LOG_LEVEL=INFO
APP_TIMEZONE=Europe/Moscow
```

Можно использовать другой OpenAI-совместимый endpoint и доступную на нём
модель. Если `OPENAI_API_KEY` пуст, весь основной MVP продолжает работать, а в
разделе AI отображается инструкция для администратора.

## Быстрая проверка

1. Отправьте `/start`.
2. Создайте обычную личную и командную задачу.
3. Нажмите «🧠 AI-помощник».
4. Напишите: `Создай командную задачу подготовить отчёт к пятнице`.
5. Проверьте карточку и нажмите «Подтвердить».
6. Убедитесь, что новая задача появилась в командном пространстве.
